# KirinYT 1.9.5.8 Beta

Pre-release · 15 November 2026 (MYT)

- Correct the installed plugin directory passed to yt-dlp. The path now points to the KirinYT plugin package that directly contains the `yt_dlp_plugins` namespace.
- Ensure the bundled Bilibili extractor can load for metadata extraction, format discovery and download requests.

- Add a Kotlin regression verifying that the plugin directory points to the namespace package root and that the extractor file is installed beneath it.
- Run the Bilibili Python engine regressions and the KirinYT Bilibili Kotlin unit tests before building the signed beta APKs.
