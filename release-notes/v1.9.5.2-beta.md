# KirinYT 1.9.5.2 Beta

Pre-release · 14 October 2026 (MYT)

## Bilibili format recommendations

- On Android 10 and newer, the default download card and Suggested format list check hardware decoder support for the recommended AV1 video's resolution and frame rate.
- If AV1 is not hardware-supported and a hardware-supported H.264 stream exists at the same resolution, frame rate and container, recommend that H.264 stream instead. Every original format remains selectable in the card.
- Keep explicit codec/format preferences, custom sorting and file-size preferences. Manual selections, including AV1, are not rewritten at download time. Unknown decoder capabilities keep the existing recommendation.
- Other websites keep their existing recommendation behavior. KirinDL/SealPlus selection modes are not changed by this KirinYT release.

## Prevent silent video fallback

- A normal Bilibili video download now requires both video and audio in standalone fallback choices. Previously a missing audio format could silently fall through to a video-only file, including yt-dlp's `best` fallback when only incomplete formats were available.
- Keep the selected video with its chosen audio or another available audio track. If no suitable pair or combined video/audio stream exists, report a format error instead of accepting a silent video.
- The deliberate Remove audio option still works. Existing CDN recovery, downloader selection and manual format IDs are preserved.

## Validation and limits

- 19 Python engine regressions cover format selection, missing audio, alternate audio, combined streams, deliberate video-only downloads, playback extraction and interrupted transfer recovery.
- Eight new Android policy tests cover same-quality H.264 recommendations, supported/unknown AV1 hardware, explicit preferences, other websites, dimensions, frame rates and manual format IDs. The six existing recovery tests remain enabled. Release workflows run both suites before building and verifying signed APKs.
- For the reported `BV16m421g7iL?p=1`, format `100026` is AV1. A fresh primary-CDN sample decoded 3,597 frames through 2:00, with changing frames beyond the reported 1:09 freeze. A backup connection ended early during a separate range test.
- This is a recommendation and missing-audio fix. It does not establish why the previously downloaded phone file froze, repair that existing file, or prove that the entire four-hour video is healthy. Actual device playback still needs verification.

After updating, create a new card from the Bilibili link so it receives a fresh recommendation. Existing queued/manual selections stay selected. For the reported video, the available H.264 1080p stream was `30080`, with AAC audio `30280`; availability can change.
