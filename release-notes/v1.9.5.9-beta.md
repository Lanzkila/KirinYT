# KirinYT 1.9.5.9 Beta

Pre-release · 15 November 2026 (MYT)

## Download engine rollback

- Restore the download/extraction implementation files to the verified KirinYT 1.9.3 source snapshot.
- Remove the custom Bilibili Python extractor, format policy, plugin installer and CDN recovery loop added after 1.9.3.
- Return Bilibili metadata, format discovery and downloads to the original yt-dlp path used by the 1.9.3 baseline.
- Keep the newer app version number so this rollback can be installed as an update without lowering Android's versionCode.

## Workflow

- Replace Bilibili-only CI tests with the regular KirinYT unit-test suite.
- Run unit tests before assembling the signed beta APKs and verifying their signatures.
