# KirinYT 1.9.5.7 Beta

Pre-release · 15 November 2026 (MYT)

## Bilibili format compatibility

- Restore the normal yt-dlp fallback order used by KirinDL. KirinYT no longer adds an extra `acodec!=none` condition to standalone fallback formats.
- Keep the selected video/audio combinations first. When a separate audio track is unavailable, the fallback behaves like KirinDL instead of rejecting an otherwise usable video format.
- Preserve manual format IDs and the hardware-aware AV1 recommendation.

## Playback extraction

- Determine whether page/API playback data is usable from the formats yt-dlp can actually extract.
- Treat CDN mirror mapping as retry metadata only. Missing mirror entries no longer cause a valid stream payload to be discarded.
- Keep the KirinYT-specific localized URL, missing-page metadata recovery, bounded CDN retry and range-resume implementation.

## Validation

- Add a regression for page and API playback data when no mirror mapping is available.
- Update selector regression coverage for KirinDL-compatible fallback behavior.
- The pre-release workflow runs the Python Bilibili engine suite, Kotlin Bilibili tests, APK build and signature verification.
