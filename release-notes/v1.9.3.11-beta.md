# KirinYT 1.9.3.11 Beta

Pre-release · 14 October 2026

## Bilibili recovery

- Added KirinYT's Bilibili interrupted-download recovery based on the KirinDL v3.2.0.11 recovery patch.
- Supports both full `bilibili.com` links and short `b23.tv` links.
- When aria2 reports transport failures such as `Got EOF from the server`, remote connection closure, reset, timeout, HTTP 403/410 or server-side 5xx errors, KirinYT refreshes the Bilibili extraction instead of failing immediately.
- Tries up to two backup stream URLs supplied directly by Bilibili for the same stream.
- Keeps the selected format IDs, downloader, cookies, output choices and partial-file state during recovery.
- Uses bounded retries so a dead stream cannot loop forever.

## Download progress

- Added a visible **Retrying** transfer stage while Bilibili recovery is running.
- Retrying the same video destination no longer makes KirinYT mislabel it as an audio transfer.
- Video, audio, merge and post-processing stages remain separate after a recovery attempt.

## Fresh Bilibili URLs

- Bilibili downloads bypass cached `info.json` playback URLs so recovery performs a fresh extraction and does not reuse an expired CDN URL.
- KirinYT preserves the normal cached-info behavior for other supported sites.

## Validation

- Added unit coverage for Bilibili and `b23.tv` detection, EOF recovery, downloader/format preservation, bounded retries and non-retryable failures.
- Release and pre-release builds now run the KirinYT Bilibili recovery tests before APK assembly.

This is a beta recovery build. Real-device CDN behavior can still vary by Bilibili region, account and network.
